# SCENARIUM Wave

Use this skill to create or update SCENARIUM waves.

## Wave requirements

- Define a product-neutral scenario/evidence goal.
- Identify affected modules and consumer repos.
- Name the duplicated consumer code targeted for deletion.
- Break the wave into small pulses with validation.
- Keep domain metrics, scoring policy, and runtime behavior in consumers.
